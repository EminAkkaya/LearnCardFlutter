# Çevrimdışı EN→TR sözlük

`en_tr.sqlite.gz`, [Wiktionary](https://www.wiktionary.org/) verisinden (wiktextract dökümleri,
kaikki.org) `tool/dictionary/build_en_tr.py` ile üretilmiştir.

Lisans: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0), © Wiktionary katkıcıları.
Bu lisans yalnızca sözlük verisini kapsar; uygulama koduna uygulanmaz. Uygulamada atıf:
Ayarlar → Uygulama Bilgisi → "Sözlük Verisi" ve kelime sayfasındaki "Kaynak: Wiktionary" satırı.
